# OCN — First 20 Targets

**Purpose:** maximize speed to M4/M5 while preserving the path to large M6–M8 platform customers.

Targets are ranked by a mix of: active agent deployment, cost of failure, transaction frequency, integration leverage, and likely speed of learning. Public activity is a reason to approach them, not evidence they want to buy.

## Wave 0 — M4 repeat payer: fastest independent proof

### 1. Independent x402 / MCP agent developer
**Goal:** 20+ paid OCN trusted events across two sessions.
**Offer:** free testnet integration; `freshness`, `authority`, `payment.intent` through JS Guard/MCP.
**Why first:** can prove independent repeated demand before enterprise procurement.

### 2. AWS AgentCore Payments developer / builder
**Public signal:** AgentCore Payments is GA and discovers/pays x402 services.
**Offer:** use OCN as a semantic trust service from an AgentCore transacting agent; wallet budget stays in AgentCore, intent/authority semantics stay in OCN.
**Proof:** AgentCore -> OCN -> x402 settlement -> trust receipt.

### 3. Coinbase/x402 ecosystem developer
**Offer:** add OCN to a buyer that already uses Bazaar/x402 and measure calls/day and repeat rate.

# Qualification rule

Do not spend founder time on a target unless they can provide at least one of:
- real agent traces/actions;
- a measurable review/fraud/audit problem;
- a platform distribution path;
- outcome/override labels;
- a realistic paid-pilot owner/budget.
