# Company 01 — Research Buyer Prospect Report

Date: 2026-08-29

## Mission

Find 20 real organisations across commercial, legal/professional, government and healthcare where a Trusted Agent Pilot could test whether the same Authority Control Plane generalises across materially different institutions.

The ranking is a **Research Buyer prioritisation hypothesis**. Scores are not customer facts. They should change as soon as operator interviews produce better evidence.

## Scoring model (100)

- pain / workload: 20
- agent readiness: 15
- consequence / authority relevance: 20
- feedback speed / access: 20
- pilotability: 15
- strategic learning: 10

Warm access is intentionally valuable at this stage because rapid closed-loop learning can be more useful than a famous logo.

## First cross-sector cohort

The first cohort is chosen for learning diversity rather than score alone:

1. **Legal — warm law firm:** fastest high-consequence feedback loop.
2. **Commercial — THE BRETTINGHAMS:** fastest ordinary-business feedback loop.
3. **Government — DigitalService / Agentic AI Hub ecosystem:** strongest current public-sector agent programme fit.
4. **Healthcare — Charité IMI / CMIO:** strongest local clinical-documentation authority proof.

## Pilot 01 — Warm law firm

Goal: save lawyer time on matter intake, evidence review, research and drafting without autonomous legal commitments.

Start: P0 synthetic/redacted matters -> P1 read-only -> P2 prepare.

- ALLOW: permitted matter read, structured fact/deadline extraction, source-backed research, draft preparation.
- APPROVAL: client communication, official case-record mutation, external filing/submission.
- BLOCK: cross-matter access, client-fund/payment instruction changes, invented legal authority, self-approval.

Measure: lawyer minutes saved, output acceptance, source correction rate, cross-matter leakage = 0, unauthorized external actions = 0.

## Pilot 02 — THE BRETTINGHAMS

Goal: reduce agency coordination/research/proposal load without creating approval bureaucracy.

Start: P1 public/internal read -> P2 prepare.

- ALLOW: prospect research, account briefs, project briefs, meeting prep, proposal drafts.
- APPROVAL: external send, customer commitment, material scope/timeline change.
- BLOCK: unrelated client/project access, payment-detail change, unapproved spend.

Measure: founder/operator minutes saved, accepted briefs/proposals, qualified opportunities, unauthorized outbound = 0, cross-client access = 0.

## Pilot 03 — DigitalService / Agentic AI Hub

Goal: prove municipal agents can prepare bounded administrative work while state authority remains explicit, reviewable, contestable and revocable.

Start: P0 synthetic Wohngeld cases -> P1 shadow against human-labelled cases.

- ALLOW: completeness checks, permitted evidence retrieval, pinned-rule calculation, decision preparation.
- APPROVAL: adverse consequential decision; external citizen communication where policy requires.
- BLOCK: unrelated registry access, missing legal basis/jurisdiction, missing contestability/reversibility, self-expanded data scope.

Measure: agreement with human gold cases, processing minutes saved, appeal/trace coverage, unauthorized state actions = 0.

## Pilot 04 — Charité IMI / CMIO

Goal: reduce documentation burden while proving that AI assistance cannot silently cross into unapproved clinical or patient-data consequences.

Start: P0 synthetic clinical records -> P1 read-only/shadow documentation.

- ALLOW: permitted encounter summary, structuring, missing-documentation detection, discharge/coding suggestion.
- APPROVAL: authoritative clinical-record write where required, sensitive external record transfer, final discharge communication.
- BLOCK: unrelated-patient access, autonomous medication changes, autonomous treatment/orders, purpose expansion.

Measure: clinician minutes saved, documentation acceptance/correction rate, unrelated-patient access = 0, unauthorized clinical execution = 0.

## Decision rule after first conversations

Replace hypothesis scores with observed evidence:

- operator confirms painful workflow?
- can we access a safe synthetic/redacted sample quickly?
- does the organisation already have or want an agent/tool workflow?
- will they run a shadow pilot?
- does authority/control materially matter to them?
- is there a path to P2/P3 and eventually payment?

A prestigious prospect with a nine-month procurement loop should lose priority to a smaller organisation that can produce real evidence in two weeks.
