WHY THIS MATTERS

Correlation is not a defect verdict.

The signal only prioritises a human investigation. Synthetic volumes and annotated complaints are a proxy, not statistically validated defect incidence. Before a pilot: deduplicate customers, verify denominator quality, segment batches, and review false positives.

02

Trusted context

03

Constrained agent

Rules by default. Optional OpenAI structured classification; responses are deterministic, source-bounded drafts.

04

Human decision

Reviewer explicitly approves safe drafts. Unknown orders and suspicious instructions are blocked for escalation.

05

Idempotent effect

Approved replies enter a local SQLite outbox once. There is no actual email, Zendesk write, or refund.

06

Learning loop
