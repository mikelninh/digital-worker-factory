# LaunchCheck Privacy Policy

_Last updated: 1 October 2026_

LaunchCheck is a read-only website preflight tool.

## Data processed

When you use LaunchCheck, it processes the **public website URL you provide** and the public HTTP/HTML content and headers returned by that website. It may also request a bounded sample of same-origin links found on that page to check whether they return HTTP errors.

## Purpose

This data is processed only to generate the requested website audit, including launch blockers, warnings, passes, and supporting evidence.

## Accounts and sensitive data

LaunchCheck v0.1 does not require a LaunchCheck account. It is not designed to receive credentials, private URLs, raw conversation history, payment information, or other sensitive personal data. URLs containing embedded credentials and private/local network targets are rejected.

## Storage

LaunchCheck v0.1 does not intentionally persist audit reports or website content in an application database. Infrastructure providers may retain standard operational or security logs under their own retention and security practices.

## Third-party infrastructure

LaunchCheck currently runs on Supabase infrastructure and uses public DNS resolution to help reject private or reserved network targets.

## Contact

For privacy questions or removal requests concerning LaunchCheck-owned data, open an issue in the public repository: https://github.com/mikelninh/digital-worker-factory/issues

This policy will be updated before any release that introduces user accounts, persistent audit history, billing, analytics tied to users, or additional categories of personal data.
