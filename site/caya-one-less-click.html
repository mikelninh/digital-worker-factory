Proof, not buzzwords.

The point of this exercise is not to imitate a production system. It is to make the job requirements inspectable in code.

AWS Lambda

Deployable handler shape

A Lambda-compatible webhook handler with explicit input validation, structured output and no hidden model authority.

Webhooks + Zapier

Integration boundary

Documented Zapier → Webhook → Lambda adapter flow with replay-safe event handling.

PostgreSQL

Real SQL exercise

Schema, idempotency constraint, composite index and an EXPLAIN (ANALYZE, BUFFERS) query path — without inventing benchmark numbers.

AI control

Interpretation ≠ authority

Classification can suggest what is happening; deterministic policy decides whether the workflow may advance.

Operations

Observable hand-offs

Each stage leaves a trace: received, checked, classified, enriched, policy-evaluated, prepared and audited.

Reliability

Regression before autonomy

30 synthetic scenarios cover routing, urgency, human boundaries, trace completeness and duplicate delivery.

Are we up to the role?

Yes. The strongest overlap is not a specific AI library — it is the engineering habit: understand the workflow, remove manual steps, integrate systems, keep control outside the model and prove the behaviour with tests.
