THE BRETTINGHAMS arbeitet mit festen interdisziplinären Scrum-Teams, flachen Hierarchien und hoher Eigenverantwortung. Genau deshalb sollte ein Agent möglichst viel Vorbereitung autonom erledigen können, ohne unbemerkt Kunden- oder Scope-Verpflichtungen einzugehen.

Kleinster sinnvoller Test

Eine echte, aber nicht sensible Aufgabe aus eurem Alltag.

  1. Ein aktuelles Briefing, einen Prospect oder eine Meeting-Situation auswählen.
  2. Zeigen, welchen Output ein starkes Teammitglied normalerweise erstellt.
  3. Der Agent erzeugt denselben Arbeitsstand unter klaren Autoritätsgrenzen.
  4. Side-by-side Review: nützlich / korrigieren / weg damit.
  5. Wir messen gesparte Minuten und ob die Controls helfen oder stören.
