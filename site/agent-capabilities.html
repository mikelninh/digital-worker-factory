What this proves

Not a chatbot. A controlled worker.

The interesting part is not that an LLM can generate text. It is that the surrounding system makes tool use, evidence, permissions and failure states explicit and testable.

Capabilities are named

Workers receive a small, typed set of tools instead of unrestricted access.

Risky actions stop

Blocked before network when a write or external action lacks the required authority.

Every attempt leaves a trace

Executed, blocked, shadowed and failed paths are inspectable and replayable.

Autonomy is earned

Synthetic regression cases test missing evidence, tool misuse, loops and unsafe actions.
