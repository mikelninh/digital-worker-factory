What it does

From manual handoffs to one inspectable workflow.

The useful outcome is simple: the worker gathers the right inputs, prepares the work, stops when authority is missing, and leaves a trace a human can understand.

1 · ReadLoad only the permitted case, document or data sources.
2 · ReconcileResolve duplicated, missing or inconsistent inputs.
3 · PrepareCreate the brief, draft or structured next action.
4 · Act safelyExecute allowed work; stop for approval when consequence increases.

Technical depth

Underneath the simple demo: fail-closed runtime control.

For an engineer, this is the deeper proof: capabilities are typed, policy decisions are deterministic, provider calls sit behind approval gates, and every path can be traced and regression-tested.

Named capabilitiesWorkers receive explicit tool contracts instead of unrestricted access.
Blocked before networkA write or external action without required authority is stopped before the provider call.
Human approvalConsequential writes are approval-gated; an approved write results in exactly one provider call.
Unknown capability fail closedRequests outside the registered capability set do not silently degrade into model improvisation.
Shadow mode: zero external callsThe same workflow can be evaluated without producing side effects.
Audit + replayExecuted, blocked, shadowed and failed attempts emit a trace for inspection and regression testing.
