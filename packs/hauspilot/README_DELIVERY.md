# Delivery truth

What exists now:

- reusable workflow templates
- client configuration format
- deployment-pack compiler
- safety/template eval suite
- browser preflight/setup wizard
- sample synthetic cases
- connector contract
- post-sale delivery checklist

What is intentionally not claimed yet:

- production mailbox OAuth
- live ERP integration
- automatic external actions
- measured customer accuracy/time savings
- a production AI inference runner

The next runtime milestone is a provider-backed shadow analyzer that consumes one canonical case + client context and returns the shared structured output contract. It should have no write tools and should default to no persistence where supported.
