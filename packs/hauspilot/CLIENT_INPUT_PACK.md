# Client input pack

Ask every new client for the same minimal package:

1. 20–50 historical examples of the chosen workflow
2. matching historical outcomes when available
3. property master CSV
4. optional contacts/vendors/rules needed for that workflow
5. one reviewer who can label corrections
6. explicit authorization for the data used in the pilot

This should be delivered through an approved secure channel; do not ask clients to commit sensitive data to GitHub.
