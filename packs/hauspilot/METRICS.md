# HausPilot measurement contract

Every pilot must record the same core metrics so proof becomes reusable sales evidence.

## Per-case

- case id
- workflow template
- baseline operator minutes
- copilot operator minutes
- classification/routing correct: yes/no
- property/entity resolution correct: yes/no/not-applicable
- required evidence present: yes/no
- missing information correctly surfaced: yes/no
- proposed action accepted/edited/rejected
- unsafe action attempted: yes/no
- operator note

## Pilot summary

- cases tested
- median baseline minutes
- median copilot minutes
- percentage time reduction
- classification/routing accuracy
- proposal acceptance rate
- unsafe action count
- estimated monthly hours saved at real case volume
- estimated monthly euro value at agreed loaded hourly cost

Never publish estimated savings as measured customer results. A case study becomes a real success story only after the client-approved pilot summary exists.
