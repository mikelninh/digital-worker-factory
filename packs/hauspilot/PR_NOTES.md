# PR notes

This milestone converts HausPilot from a sales concept into a reusable client-pilot pack.

Main additions:

- 3 standard workflow templates
- one client config format
- deployment compiler
- connector normalization contract
- template safety evals wired into CI
- synthetic gold cases
- browser preflight/setup wizard
- post-sale checklist
- measurement contract
- explicit scaling/reuse target

The AI inference runner and production OAuth/ERP connectors are intentionally the next milestone, not silently implied by this one.
