# Open Capability Network — Milestone Gates

These are the milestones worth notifying on. A milestone flips only when its evidence gate is satisfied.

## M0 — First machine payment proof ✅

Evidence:
- successful Base Sepolia x402 settlement.
- HTTP 200 result.
- payment did not grant authority.

## M1 — OpenCapabilities network defined ✅

Evidence:
- master plan saved.
- machine-readable catalog implemented.
- 100+ capability universe mapped.
- provider adapter contract implemented.
- government launch/procurement pack exists.

## M2 — Public trust rail live

Gate:
- public HTTPS gateway reachable.
- `/.well-known/open-capabilities.json` reachable.
- health check green.
- at least one callable capability.
- contract/eval CI green.

## M3 — First horizontal trust capability live

Gate:
- `judge.output.v1` or equivalent non-HausPilot capability reachable through OCN.
- provider timeout/error contract tested.
- published eval/golden-case evidence.

## M4 — First external agent user

Gate:
- external wallet/agent/integrator discovers or calls OCN.
- not our own buyer wallet.
- call/feedback evidence recorded without secrets.

## M5 — First government/public-IT technical buyer conversation

Gate:
- qualified authority/public-IT conversation.
- one real workflow identified.
- authority boundary and success metric captured.
- next step agreed.

## M6 — First paid institutional pilot

Gate:
- signed/accepted paid pilot or equivalent binding purchase.
- target EUR 25k+ booked.
- workflow + metrics + data/authority scope defined.

## M7 — First repeat deployment

Gate:
- second institution/authority uses a capability or pack originally proven elsewhere.
- materially less custom work than first deployment.

## M8 — First measured scale proof

Gate:
- hosted deterministic capability load-tested.
- p50/p95/p99 and error rate published.
- first 100 RPS sustained gate, then 1k RPS gate tracked separately.

## M9 — Sovereign/customer-controlled deployment validated

Gate:
- at least one capability deployed in customer/public-IT-controlled environment.
- model/provider portability and audit export validated.

## M10 — Network business proof

Gate:
- 3 paying institutional customers/pilots.
- at least one repeat deployment.
- at least 10 live capabilities or a smaller set with strong repeated demand.
- real outcome evidence published.

## Long-term gates

- EUR 1m ARR.
- public-IT/platform channel contract.
- 1m annual external capability calls.
- 100m annual calls.
- multi-country capability provider.
- interoperable OpenProof/OpenAction/OpenReceipts standard adopted outside our own products.

Notifications should report only new gates that have actually flipped and link the supporting evidence.
