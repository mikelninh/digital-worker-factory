# Government / Public-IT Buyer Pipeline

**Goal:** turn Open Capability Network proof into one paid EUR 25k+ pilot within 30 days, while building the distribution relationships that can replicate a capability across many authorities.

## Priority 0 — message

Do not lead with crypto, “autonomous agents”, AGI, or replacing civil servants.

Lead with:

> **Bring your agents. We provide the verified capabilities they need.**

Then:

> Your infrastructure and Fachverfahren remain authoritative. We add bounded specialist capabilities, evidence, independent evaluation and deterministic authority gates so agents are easier to trust and reuse.

## Qualification filter

Prioritize a buyer/partner when at least three are true:

- already experimenting with agentic/GenAI workflows.
- document/rule/evidence-heavy workflow.
- clear human-review bottleneck.
- multiple authorities/teams could reuse the capability.
- access to an existing public IT provider/integration layer.
- measurable baseline exists.
- can run synthetic/de-identified shadow pilot quickly.
- budget path for a focused pilot exists.

## Tier 1 — distribution multipliers

### BMDS / DigitalService Agentic AI Hub

**Why:** active agentic administration program; startup/public-sector scaling is central to the program.

**Offer:** shared trust/capability layer that multiple Hub agents can reuse.

**Demo:** `document.preflight.v1` + `judge.output.v1` + proof/receipt chain.

**Ask:** 30-minute technical discovery; identify one second-round workflow where a reusable capability reduces review work.

### govdigital

**Why:** shared public-sector infrastructure and public IT provider network.

**Offer:** model-neutral capability gateway / integration pattern deployable through public IT providers.

**Demo:** machine discovery catalog + customer-VPC/sovereign deployment contract.

**Ask:** architecture review and one provider/authority integration pilot.

### Dataport

**Why:** large public IT footprint and ability to operate shared services.

**Offer:** provider-operated OCN capability pack with evidence/eval contracts.

**Ask:** one bounded workflow + one consuming agent stack.

### AKDB / Komm.ONE / ekom21 / KDO / DVZ

**Why:** municipality/state distribution and practical Fachverfahren integration leverage.

**Offer:** reusable preflight/verification capability that can be replicated across authorities rather than bespoke agent build per municipality.

## Tier 2 — direct pilot buyers

Target authorities with high-volume document/evidence workflows:

- grants/funding.
- building/permit processes.
- benefits/application prechecks.
- procurement document review.
- internal correspondence/case routing.
- legal/rule provenance checks.

Default first pilot: application preflight or agent output review, never final entitlement/rejection.

## Tier 3 — faster-cash parallel buyers

Regulated enterprises can validate the same trust rail while government procurement progresses:

- insurers.
- hospitals/health networks for non-autonomous review pilots.
- legal/compliance teams.
- housing/property operators.
- utilities.
- integrators building enterprise/government agent systems.

The same OpenCapabilities/OpenJudge/OpenProof architecture applies; only domain pack and deployment constraints change.

## Funnel target — first 30 days

```text
30 high-quality targets
 -> 12 responses / introductions
 -> 8 discovery calls
 -> 4 technical demos
 -> 2 scoped pilot proposals
 -> 1 paid EUR 25k+ pilot
```

These are operating targets, not historical conversion claims.

## Discovery call outcome

Leave every call with these six facts:

1. workflow.
2. current volume and handling time.
3. failure/risk pattern.
4. final human authority point.
5. technical integration owner/public IT provider.
6. measurable pilot success threshold.

If those facts are not available, do not propose a large custom build. Offer a short workflow/evidence workshop first.

## Pilot proposal skeleton

**Problem:** one measurable review bottleneck.  
**Capability:** one or two bounded OCN capabilities.  
**Data:** synthetic/de-identified first; explicit processing profile for anything else.  
**Authority:** human/authoritative system unchanged.  
**Evidence:** 30-100 golden cases + before/after baseline.  
**Duration:** 30 days.  
**Commercial hypothesis:** EUR 25k-50k fixed scope.  
**Exit:** scale only if quality/outcome gates pass.
