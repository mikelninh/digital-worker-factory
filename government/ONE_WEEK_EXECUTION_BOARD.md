# Open Capability Network — One Week Execution Board

This board compresses the long-term roadmap into a one-week evidence sprint. It is not a claim that national procurement, certification or billion-request throughput can be completed in seven days.

## Day 1 — CONNECT

- [x] save master plan.
- [x] normalize first capability catalog.
- [x] expose discovery route in gateway.
- [x] add per-capability detail route.
- [x] define provider adapter contract.
- [x] add request correlation IDs.
- [x] government buyer/procurement pack.
- [x] first public-sector landing-page source.

**Gate:** portfolio is represented as one machine-readable network rather than isolated products.

## Day 2 — HARDEN

- [x] capability schema/readiness contract tests.
- [x] adapter timeout + HTTPS controls.
- [x] request-ID validation/propagation.
- [x] scale architecture.
- [ ] idempotency contract for paid/consequential requests.
- [ ] per-tenant usage/rate-budget abstraction.
- [ ] provider circuit breaker.
- [ ] explicit threat model document + tests mapped to threats.

**Gate:** no permission, payment or readiness boundary depends on model instructions.

## Day 3 — PROVE

- [x] existing x402 settlement recorded.
- [x] readiness labels tied to evidence.
- [ ] public proof/eval index per capability.
- [ ] government application-preflight golden case bundle.
- [ ] public proof dashboard update.
- [ ] signed/detached receipt design.

**Gate:** claims can be audited without trusting the pitch.

## Day 4 — CONNECT HIGH-LEVERAGE PROVIDERS

- [ ] `judge.output.v1` hosted provider adapter.
- [ ] `document.preflight.v1` hosted provider adapter.
- [ ] `legal.gitlaw.de.v1` bounded provider adapter.
- [ ] `openproof.verify.v1` provider adapter.

**Gate:** at least two non-HausPilot capabilities callable behind the common envelope.

## Day 5 — DISTRIBUTE

- [x] buyer pipeline.
- [x] 30-day pilot commercial hypothesis.
- [x] public-sector landing-page source.
- [ ] public HTTPS deployment.
- [ ] one-page proof/eval PDF or printable page.
- [ ] outreach queue with named contacts/roles and status.
- [ ] integration example for HTTP + MCP consuming agent.

**Gate:** one link can be sent to a technical buyer.

## Day 6 — SCALE TEST

- [ ] load-test harness.
- [ ] hosted 100 RPS deterministic test.
- [ ] p50/p95/p99 + errors + resource metrics.
- [ ] failure injection.
- [ ] rate/abuse/spend caps validated.

**Gate:** publish first measured throughput baseline; no speculative scale claims.

## Day 7 — EXTERNAL LOOP

- [ ] external agent discovers and calls a capability.
- [ ] one public-sector/public-IT technical conversation.
- [ ] one scoped pilot proposal.
- [ ] feedback/objections recorded as issues.
- [ ] next sprint selected from real evidence.

**Gate:** external usage or concrete buyer progress.

## 30-day commercial target

Primary: one paid EUR 25k+ pilot booked.

Stretch: EUR 100k booked through two pilots or one larger integration/evaluation package.

Machine-call revenue is a usage/distribution proof in month one, not the primary near-term revenue assumption.
